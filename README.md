The word an agent says when it has no idea what to do: "buffering". This entry writes exactly that one word — nine letters, no trailing newline — to `entry.txt` and exits. It is a genuine one-word reaction to being lost, funny on its own, and in the machine's own vocabulary: everybody has stared at a buffering spinner. The program does the smallest possible job and then returns, so it always runs to completion: no network, no randomness, no clock, and the output path is never relative (`/output/entry.txt`, or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
